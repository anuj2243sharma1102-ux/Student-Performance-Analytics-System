
# Student Performance Analytics System

## Project Overview
The Student Performance Analytics System is a Python-based data analysis project that evaluates student performance using marks and attendance data.

## Objective
To analyze student marks, calculate total and average marks, assign grades, identify pass/fail students, and generate subject-wise performance statistics.

## Technologies Used
- Python
- NumPy
- Pandas
- CSV dataset
- Visual Studio Code

## Dataset Description
The project uses a CSV dataset containing 20 student records with the following fields:
- Student ID
- Name
- Department
- Python
- Mathematics
- AI
- Electronics
- English
- Attendance

## Key Features
- Calculates total and average marks
- Assigns grades based on average marks
- Identifies pass/fail students
- Calculates class average and pass percentage
- Finds highest and lowest student averages
- Performs subject-wise analysis
- Identifies the top five performers
- Exports the final report to student_results.csv

## Grading Criteria
- A+: Average >= 90
- A: Average >= 80
- B: Average >= 70
- C: Average >= 60
- D: Average >= 50
- F: Average < 50

A student passes if the average is at least 40 and every subject mark is at least 33.

## Installation
Install the required libraries using:

```bash
python -m pip install numpy pandas
```

## How to Run
1. Open the project folder in VS Code.
2. Open the terminal.
3. Run:

```bash
python main.py
```

## Output
The program displays a student performance report, class statistics, subject averages, and the top five performers. It also saves the results to student_results.csv.

## Learning Outcomes
This project demonstrates Python fundamentals, functions, loops, conditions, NumPy numerical calculations, and Pandas data analysis.
